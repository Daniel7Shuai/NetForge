# NetForge

A web game for learning networking towards the CCNA. Students start in a garage with a busted laptop, learn networking in short lessons and challenges, and use what they earn to build out a network: cabling devices port to port like Cisco Packet Tracer, leasing an office and then a datacentre, and defending it from cyber attacks. Lecturers manage the content and follow progress through analytics.

Built with PHP 8 and MySQL/MariaDB on the server and Phaser 3 for the map, with no build step.
